# SQLBot 模块部署文档

> 安装时间：Fri May 15 03:10:24 AM CST 2026
> 版本：v1.8.0-ce

## 一、安装环境

| 项目 | 值 |
|------|-----|
| 安装方式 | 全新安装（离线安装包） |
| 安装包 | `sqlbot-offline-installer-v1.8.0-ce.tar.gz` |
| 目标服务器 | Ubuntu |

## 二、安装步骤

### 1. 环境检查与初始化

解压安装包后执行安装脚本，自动检测系统环境并初始化环境变量。

> 安装方式：全新安装

### 2. 运行目录设置

```
运行目录       /opt/sqlbot
配置文件目录   /opt/sqlbot/conf
```

### 3. 初始化运行目录

1. 复制安装文件到 `/opt/sqlbot`
2. 调整配置文件参数（conf 目录下）

### 4. 安装 sctl 命令行工具

```
安装路径：
  /usr/local/bin/sctl
  /usr/bin/sctl
```

`sctl` 是 SQLBot 的运维管理命令行工具，用于服务的启停、状态查询等操作。

### 5. 操作系统设置

> 防火墙未开启，忽略端口开放

若防火墙已启用，需放行端口：`8000`

### 6. 安装 Docker

> 检测到 Docker 已安装，跳过安装步骤

安装程序会自动检测 Docker 是否已安装，若未安装则自动安装。

### 7. 安装 docker-compose

> 检测到 Docker Compose 已安装，跳过安装步骤

安装程序会自动检测 docker-compose 是否已安装，若未安装则自动安装。

### 8. 加载 SQLBot 镜像

```bash
# 从离线安装包加载 Docker 镜像
docker load -i sqlbot-v1.8.0.tar
```

| 镜像 | 标签 |
|------|------|
| sqlbot | v1.8.0 |

### 9. 启动 SQLBot 服务

```bash
cd /opt/sqlbot
docker-compose up -d
```

启动流程：

```
Network sqlbot_sqlbot-network  Creating
Network sqlbot_sqlbot-network  Created
Container sqlbot  Creating
Container sqlbot  Created
Container sqlbot  Starting
Container sqlbot  Started
```

## 四、日常运维

### 服务管理

```bash
# 启动
sctl start

# 停止
sctl stop

# 重启
sctl restart

# 查看状态
sctl status
```

### Docker Compose 管理

```bash
# 查看运行状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 重启服务
docker-compose restart

# 停止服务
docker-compose down
```
