# 多语言翻译体系

## 一、整体架构

```
MySQL（原始数据）                    MongoDB（翻译存储）
┌──────────┐    自动同步/手动管理    ┌─────────────────┐
│ goods    │ ─────────────────────→ │ translation_units │
│ goods_category │ ──────────────→ │                  │
│ spec_name     │ ──────────────→ │  unitKey 唯一键   │
│ spec_value    │ ──────────────→ │  locales 多语言值  │
└──────────┘                       └─────────────────┘
         ↑ 前端 TranslationModal 读取 ↓
         └─────────────────────────────────┘
              编辑后 batchSave 写入
```

## 二、unitKey 规则

### 2.1 格式

```
{entityType}:{entityId}:{fieldPath}
```

### 2.2 各实体

| 实体类型 | entityType | fieldPath | 示例 unitKey | 说明 |
|---------|-----------|-----------|-------------|------|
| 商品 | `goods` | `name` | `goods:1:name` | SPU 名称 |
| 商品 | `goods` | `short_desc` | `goods:1:short_desc` | 短描述 |
| 商品 | `goods` | `description` | `goods:1:description` | 详细描述 |
| 分类 | `category` | `name` | `category:5:name` | 分类名称 |
| 规格名 | `spec` | `name` | `spec:2:name` | 规格名称 |
| 规格值 | `spec` | `value_{id}` | `spec:2:value_4` | 规格值 |

### 2.3 生成规则

```java
String unitKey = entityType + ":" + entityId + ":" + fieldPath;
```

## 三、同步策略

### 3.1 自动同步（仅规格）

| 操作 | 自动同步 | unitKey 示例 |
|------|---------|-------------|
| 新增规格名 | ✅ `syncSpecCreated` | `spec:2:name` |
| 新增规格值 | ✅ `syncSpecValueCreated` | `spec:2:value_4` |

### 3.2 手动管理（分类 + 商品）

分类和商品不再自动同步，通过操作栏的「翻译」按钮手动管理。

| 页面 | 实体类型 | 按钮 |
|------|---------|------|
| [CategoryList.vue](../Fronted/src/views/product/CategoryList.vue) | `category` | 操作栏 + 翻译 |
| [ProductList.vue](../Fronted/src/views/product/ProductList.vue) | `goods` | 操作栏 + 翻译 |

## 四、前端翻译弹窗

### 4.1 组件

[TranslationModal.vue](../Fronted/src/components/TranslationModal.vue)

### 4.2 流程

```
1. 点击「翻译」按钮
2. 调用 GET /admin/i18n/entities/{type}/{id}
   → 后端从 MySQL 读取原文 + MongoDB 读取翻译，合并返回
3. 前端展示表格：字段名 | zh-CN | en-US | ja-JP
4. 编辑各语言值
5. 保存 → 调用 PUT /admin/i18n/units/batch
   → 写入 MongoDB
```

### 4.3 接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `/admin/i18n/entities/{type}/{id}` | GET | 获取实体字段+翻译 |
| `/admin/i18n/units/batch` | PUT | 批量保存翻译 |
| `/admin/i18n/locales` | GET | 获取支持的语言列表 |

## 五、支持的语言

| 代码 | 语言 |
|------|------|
| `zh-CN` | 简体中文（基准） |
| `en-US` | 英语 |
| `ja-JP` | 日语 |

## 六、数据模型

### 6.1 MongoDB TranslationUnit

```json
{
  "_id": "...",
  "unitKey": "spec:2:name",
  "entityType": "spec",
  "entityId": 2,
  "fieldPath": "name",
  "fieldType": "text",
  "name": "规格名称",
  "sortOrder": 0,
  "locales": {
    "zh-CN": { "value": "颜色", "status": "approved" },
    "en-US": { "value": "Color", "status": "translated" },
    "ja-JP": { "value": "色", "status": "draft" }
  }
}
```

### 6.2 索引

| 索引名 | 字段 | 唯一 |
|--------|------|------|
| `idx_unit_key` | `unit_key` | ✅ 唯一 |
| `idx_entity` | `entity_type, entity_id, sort_order` | ❌ |
