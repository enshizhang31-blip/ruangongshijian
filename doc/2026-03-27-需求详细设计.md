# 需求详细设计

> 本文档定义销售管理系统的功能需求和业务流程。
> 关联文档：[数据库设计.md](doc/2026-03-28-数据库设计.md)、[国际化方案.md](doc/2026-03-29-国际化方案.md)

## 一、系统概述

### 1.1 系统目标

开发销售管理系统（小程序 + Web端 + 后端API），实现：
- 商品管理（SPU + SKU + SN码）
- 客户/会员管理（积分、余额、等级）
- 订单管理（创建、支付、退款）
- 数据埋点（用户行为分析）

### 1.2 三端架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              后端 API (SpringBoot)                         │
│                    统一认证 · 动态路由 · 权限控制 · 数据服务                  │
└─────────────────────────────────────────────────────────────────────────────┘
              ↑                       ↑                       ↑
              │                       │                       │
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│     Fronted     │       │     Uniapp      │       │    Backend      │
│   (Web管理端)   │       │  (用户端小程序)   │       │   (后端API)     │
├─────────────────┤       ├─────────────────┤       ├─────────────────┤
│• 商品批量管理    │       │• 商品浏览        │       │• 业务逻辑       │
│• SPU/SKU管理    │       │• 购物车          │       │• 数据持久化     │

## 二、商品模块

### 2.1 商品层级关系

```
SPU（标准产品单位）
├── 抽象的商品概念
├── 如：iPhone 15
└── 不涉及具体规格和价格

SKU（规格组合）
├── SPU + 规格组合
├── 如：iPhone 15 黑色 256G
├── 有独立的 price、image_url
└── 库存通过 SN码 数量计算

SN码（商品实例）
├── SKU 的具体实例
├── 如：序列号 SN202403010001
├── 1个SKU可以有多个SN码
└── 库存 = 在库状态(0)的SN码数量
```

### 2.2 SPU管理功能

| 功能 | 说明 |
|------|------|
| 新增SPU | 输入名称、选择分类、上传图片、填写描述 |
| 编辑SPU | 修改基本信息、图片、描述 |
| 删除SPU | 级联删除关联的SKU和SN码 |
| 上架/下架 | 批量修改SPU状态 |
| SPU列表 | 分页、搜索、筛选、排序 |

**API接口**：
```
GET    /api/admin/spu           # SPU列表（分页、筛选）
POST   /api/admin/spu           # 新增SPU
PUT    /api/admin/spu/{id}       # 编辑SPU
DELETE /api/admin/spu/{id}      # 删除SPU
PUT    /api/admin/spu/{id}/status # 修改状态（上架/下架）
GET    /api/spu                 # 小程序端SPU列表
GET    /api/spu/{id}            # SPU详情
```

### 2.6 模拟数据生成

| 功能 | 说明 |
|------|------|
| 批量造数 | 一次生成商品、SKU、规格值和SN码，便于联调和演示 |

**API接口**：
```

```

**请求参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| goodsCount | int | 20 | 商品数量 |
| skuPerGoods | int | 4 | 每个商品生成的SKU数量 |
| snPerSku | int | 5 | 每个SKU生成的SN码数量 |

### 2.6 SN码管理

| 功能 | 说明 |
|------|------|
| 手动单个录入 | 输入SN码+关联SKU |
| 批量导入 | CSV上传→预览→确认→结果报告 |
| 自动生成 | 系统自动生成一批SN码 |
| SN码查询 | 按SN码/SKU/状态查询 |
| 状态变更 | 批量作废/激活 |
| 操作日志 | 记录每个SN码的状态变更 |

**API接口**：
```
GET    /api/admin/sn            # SN码列表（分页、筛选）
GET    /api/admin/sn/{sn}       # SN码查询
POST   /api/admin/sn            # 单个录入
POST   /api/admin/sn/batch      # 批量录入
POST   /api/admin/sn/import    # CSV导入
POST   /api/admin/sn/generate  # 自动生成
PUT    /api/admin/sn/{id}/status # 状态变更
GET    /api/admin/sn/{id}/log  # SN码操作日志
```

### 2.7 库存计算规则

```
商品库存 = 该SKU下所有SN码中，状态为"在库(0)"的SN码数量

示例：
SKU: iPhone 15 黑色 256G
├── SN码1 (在库) ✓
├── SN码2 (在库) ✓
├── SN码3 (已售) ✗
└── 库存 = 2
```

## 六、订单模块

### 6.1 订单流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 待付款   │───>│ 已付款   │───>│ 已完成   │    │ 已取消   │    │ 退款中   │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
     │              │              │                            │
     │              │              │                            ▼
     │              │              │                      ┌─────────┐
     │              │              │                      │ 已退款   │
     │              │              │                      └─────────┘
     │              │              │
     ▼              ▼              ▼

| 3 | 已取消 | - |

### 6.5 订单金额计算

```
实付金额 = 商品总价 × 会员折扣 - 优惠金额

示例：
商品总价 = ¥1000
会员等级 = 金卡（90%折扣）
实付金额 = ¥1000 × 0.90 = ¥900
```

## 七、权限模块（管理端）

> 关联文档：[api-admin-system.md - 权限模型说明](../doc/api/Web管理端/api-admin-system.md)

### 7.1 权限模型说明

```
角色（预设模板）
├── 预设权限数组 permissions
├── 预设路由数组 routes
└── 不可修改：SUPER_ADMIN, OPERATOR, INPUTTER

员工
├── permissions: 权限数组（创建时从角色复制，之后独立）
├── routes: 路由数组（创建时从角色复制，之后独立）

有效权限 = 员工的 permissions
有效路由 = 员工的 routes

⚠️ 员工表中不存储 role_id，创建时在Java代码中从角色复制
```

### 7.2 预设角色

| 角色 | 权限范围 | 路由 | 权限标识 |
|------|----------|------|----------|
| 超级管理员 | 所有权限 | 所有路由 | `*` |
| 运营主管 | 商品/SN码/客户/订单/统计 | /dashboard, /product, /sn, /customer, /order, /statistics | `spu:*`, `sku:*`, `category:*`, `spec:*`, `sn:*`, `customer:*`, `order:*`, `statistics:*` |
| 录入员 | 商品新增、SN码操作 | /dashboard, /product, /sn | `spu:add`, `spu:edit`, `spu:view`, `sku:add`, `sku:edit`, `sku:view`, `sn:add`, `sn:import`, `sn:view`, `sn:query` |

> **说明**：角色仅作为预设模板，不可新增、编辑、删除。员工创建时，Java从角色复制权限到员工表。
