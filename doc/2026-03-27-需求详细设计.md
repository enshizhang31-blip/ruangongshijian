# 2026-03-27 需求详细设计

## 背景

随着业务发展，需要一套完整的销售管理系统，包含：
- 用户端小程序（会员商城）
- Web管理端（批量商品管理 + SN码录入）
- 后端API（统一认证、数据服务）

## 技术决策

### 小程序单端方案

- **用户端小程序**：面向客户，主打会员商城，微信登录+支付
- **SN码录入**：合并到Web管理端，支持扫码枪批量录入

### 动态路由+权限方案

- 菜单表存储前端路由和按钮权限
- 用户登录后返回路由列表+权限数组
- 前端动态注册路由，路由守卫校验权限
- 按钮级别权限通过v-permission指令控制

### CSV批量操作方案

- 支持导出标准模板
- 上传CSV后预览确认
- 批量编辑支持：分类、价格、状态、描述

#### SN码操作逻辑

```
扫描SN码
    │
    ▼
查询后端是否存在
    │
    ├── 存在 → 进入编辑模式（显示已有数据）
    │
    └── 不存在 → 进入新增模式（仅SN码填充）
            │
            ▼
         填写：商品名称、分类、价格、库存、单位、描述
            │
            ▼
         保存 → 震动+成功提示 → 返回首页
```

### 单独权限管理

| 功能 | 说明 |
|------|------|
| **角色继承** | 新用户默认继承预设角色权限 |
| **单独调整** | 可针对单个用户增删权限 |
| **权限叠加** | 单独调整的权限在角色权限基础上叠加 |
| **权限排除** | 可单独禁用某权限（即使角色包含） |

### 用户权限数据结构

```json
{
  "userId": 1,
  "username": "zhangsan",
  "roleId": 2,
  "roleName": "运营主管",
  "rolePermissions": ["product:*", "order:*", "customer:*", "statistics:*"],
  "extraPermissions": ["goods:delete"],    // 额外授予
  "excludePermissions": []                  // 额外禁用
}
```

### 最终权限计算

```
用户有效权限 = 角色权限 ∪ 额外权限 - 禁用权限
```

### 路由单独管理

| 功能 | 说明 |
|------|------|
| **路由继承** | 新用户默认继承预设角色的路由 |
| **单独调整** | 可针对单个用户增删路由 |
| **路由叠加** | 额外授予的路由在角色路由基础上叠加 |
| **路由排除** | 可单独禁用某路由（即使角色包含） |

### 用户路由数据结构

```json
{
  "userId": 1,
  "username": "zhangsan",
  "roleId": 2,
  "roleName": "运营主管",
  "roleRoutes": ["/dashboard", "/product", "/order", "/customer", "/statistics"],
  "extraRoutes": [],                 // 额外授予
  "excludeRoutes": ["/system"]       // 额外禁用（不可见）
}
```

### 最终路由计算

```
用户可见路由 = 角色路由 ∪ 额外路由 - 禁用路由
```
