> 基于当前管理端架构，以**国际化多语言**为核心设计小程序端方案。

## 一、概述

### 1.1 目标

开发微信小程序客户端，面向 C 端用户（会员），实现商品浏览、购物车、下单支付、会员中心、多语言切换等核心功能。

### 1.2 三端关系

```
后端 API (SpringBoot)
├── /api/admin/*       → Web 管理端
├── /api/app/*         → 小程序端
└── /api/admin/i18n/*  → 多语言 API（两端共享）
```

### 1.3 技术栈

| 项目 | 版本 | 说明 |
|------|------|------|
| uni-app | 3.0 | 跨平台框架 |
| Vue | 3.4 | Composition API + `<script setup>` |
| UI 组件 | uni-ui ^1.5 | 已配置 easycom 自动导入 |
| 构建 | Vite 5 | `@dcloudio/vite-plugin-uni` |
| 样式 | Sass | `sass` + `sass-loader` |
| 国际化 | vue-i18n ^9.1 | 多语言切换 |
| TypeScript | ✅ | 类型支持 |

## 二、核心设计：国际化多语言

> 小程序端的国际化与 Web 管理端**共享同一套后端多语言体系**（MySQL + MongoDB + Redis 缓存）。

### 2.1 架构总览

```
┌────────────────────────────────────────────────────────────────┐
│                     小程序端 (Uniapp)                          │
│                                                                │
│  vue-i18n (UI文案)        API 请求 (业务翻译)                   │
│  ┌─────────────┐          ┌──────────────────────────┐         │
│  │ locales/    │          │ ?locale=ja-JP            │         │
│  │ zh-CN.json  │          │ X-App-Locale: en-US      │         │
│  │ en-US.json  │          └───────────┬──────────────┘         │
│  │ ja-JP.json  │                      │                        │
│  └─────────────┘                      ▼                        │
│        │                    ┌──────────────────────┐           │
│        ▼                    │ 后端 assembleEntity  │           │
│  按钮/提示/校验              │ MySQL基础数据        │           │
│  纯前端本地管理              │ + MongoDB翻译单元    │           │
│                             │ → 合并返回翻译后数据  │           │
│                             └──────────────────────┘           │
└────────────────────────────────────────────────────────────────┘
```

### 2.2 翻译分层

| 类型 | 存储 | 管理方式 | 示例 |
|------|------|----------|------|
| **业务翻译** | MongoDB `translation_units` | Web 管理端编辑 | 商品名称、分类名称、规格值 |
| **UI 翻译** | 前端 `locales/*.json` | 前端源码维护 | 按钮文字、提示信息、校验文案 |

### 2.3 后端多语言 API（复用现有）

| 接口 | 说明 |
|------|------|
| `GET /api/app/i18n/units?entityType=goods&entityId=1` | 获取实体所有翻译单元 |
| `GET /api/app/i18n/units/status?entityType=goods&entityId=1` | 翻译完成度 |
| `GET /api/app/i18n/locales` | 支持的语言列表 |
| `GET /api/app/i18n/entities` | 搜索实体（商品/分类/规格） |

> ⚠️ 小程序端**只读**翻译数据，不调用 `/api/admin/i18n/*` 的编辑接口。

### 2.4 商品多语言查询流程

```
小程序请求: GET /api/app/goods/1?locale=en-US

后端处理:
1. MySQL 查询商品基础数据 (id, category_id, brand, image_url, created_at)
2. MongoDB 查询 translation_units (entityType=goods, entityId=1)
3. I18nService.assembleEntity("goods", 1, "en-US")
   → 遍历 units，按 locale 取值 + fallback 链
   → 合并为 { name: "...", description: "...", attrs: {...} }
4. 返回合并后的 JSON
```

### 2.5 Fallback 链

当前配置（`application.yml`）：

```yaml
i18n:
  default-locale: zh-CN
  fallback-chain:
    zh-TW: [zh-CN, en-US]
    ja-JP: [en-US, zh-CN]
    en-US: [zh-CN]
```

小程序端无需实现 fallback 逻辑，后端 `resolveLocaleValue` 已封装好。

### 2.6 语言切换

```
用户在设置页切换语言 → vue-i18n.locale = 'en-US'
→ 所有 UI 文案立即切换
→ 商品列表/详情重新请求（携带 ?locale=en-US 或 Header: X-App-Locale）
→ 显示对应语言的业务数据
```

### 4.2 请求自动携带语言

```typescript
// utils/request.ts
import { useAppStore } from '@/stores/app'

const http = uni.request  // uni-app 网络请求

export function request(options) {
  const appStore = useAppStore()
  return http({
    ...options,
    header: {
      ...options.header,
      'X-App-Locale': appStore.locale  // 携带当前语言
    }
  })
}
```

### 4.3 语言存储与持久化

```typescript
// composables/useI18n.ts
export function useAppI18n() {
  const locale = ref(uni.getStorageSync('app-locale') || 'zh-CN')

  function setLocale(lang: string) {
    locale.value = lang
    uni.setStorageSync('app-locale', lang)
    // vue-i18n 同步
    i18n.global.locale = lang as any
  }

  return { locale, setLocale }
}
```

## 七、注意事项

1. **翻译数据只读**：小程序端不调用 `/api/admin/i18n/*` 编辑接口
2. **语言持久化**：用户选择的语言存储在 `uni.storage` 中，下次启动自动恢复
3. **首次加载语言**：根据微信系统语言自动匹配，未匹配到则默认 `zh-CN`
4. **UI 文案不走后端**：按钮、提示等先用 `vue-i18n` 本地管理
5. **商品翻译由后端组装**：前端请求时携带 `?locale=xx`，后端自动合并 MySQL + MongoDB 数据返回
6. **兼容 Web 端**：与 Web 管理端共享同一套多语言后端
