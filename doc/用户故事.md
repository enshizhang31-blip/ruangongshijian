# 用户故事

> 本文档从各角色出发，描述销售管理系统的用户需求。
> 关联文档：[需求详细设计.md](../doc/2026-03-27-需求详细设计.md)、[API接口文档](../doc/api/)

---

## 一、角色与权限

| 角色 | 权限 | 可见路由 |
|------|------|----------|
| 超级管理员 | `*` (所有权限) | 所有路由 |
| 运营主管 | `spu:*`, `sku:*`, `sn:*`, `customer:*`, `order:*`, `statistics:*` | /dashboard, /product, /sn, /customer, /order, /statistics |
| 录入员 | `spu:add`, `spu:edit`, `spu:view`, `sku:add`, `sku:edit`, `sku:view`, `sn:add`, `sn:import`, `sn:view`, `sn:query` | /dashboard, /product, /sn |

## 二、录入员用户故事

### US001 - 登录系统

```
作为 录入员
我希望 使用用户名密码登录系统
以便 能够访问工作台
```

**验收标准**：
1. 输入正确用户名密码，登录成功跳转首页
2. 输入错误用户名密码，提示"用户名或密码错误"
3. 账号被禁用时，提示"账号已被禁用"

### US002 - 查看仪表盘

```
作为 录入员
我希望 查看首页统计数据
以便 了解今日工作概况
```

**验收标准**：
1. 显示今日新增商品数量
2. 显示今日新增SN码数量
3. 显示待处理任务数

### US003 - 新增商品SPU

```
作为 录入员
我希望 新增商品SPU
以便 能够添加新商品到系统
```

**验收标准**：
1. 能够输入SPU名称、选择分类、上传图片
2. 保存成功后，SPU出现在商品列表
3. 必填字段为空时，提示校验错误

### US004 - 编辑商品SPU

```
作为 录入员
我希望 编辑已有商品SPU
以便 能够修改商品信息
```

**验收标准**：
1. 能够查看SPU详情
2. 能够修改SPU信息
3. 保存成功后，列表显示更新后的信息

### US005 - 新增SKU

```
作为 录入员
我希望 为SPU新增SKU
以便 能够添加具体规格的商品
```

**验收标准**：
1. 能够选择SPU、填写规格、输入价格
2. SKU编码自动生成或手动输入
3. 保存成功后，SKU出现在SPU详情中

### US006 - 手动录入SN码

```
作为 录入员
我希望 手动录入SN码
以便 将商品入库
```

**验收标准**：
1. 能够输入SN码并关联SKU
2. SN码重复时，提示错误
3. 录入成功后，SN码状态为"在库"

### US007 - 批量导入SN码

```
作为 录入员
我希望 通过CSV文件批量导入SN码
以便 快速批量入库
```

**验收标准**：
1. 能够上传CSV文件
2. 系统预览导入数据
3. 导入成功后显示成功数量
4. 失败时显示错误明细

### US008 - 查询SN码

```
作为 录入员
我希望 根据SN码查询商品信息
以便 核实商品状态
```

**验收标准**：
1. 输入SN码能够查询到对应商品
2. 显示SN码的当前状态（在库/已售/作废）
3. 查询不到时提示"未找到"

```

### US202 - 员工列表

```
作为 超级管理员
我希望 查看员工列表

```

**验收标准**：
1. 分页显示员工列表
2. 显示员工姓名、角色、状态
3. 支持搜索员工

```
作为 超级管理员
我希望 新增员工账号

```

**验收标准**：

```

**验收标准**：

作为 超级管理员
我希望 管理前端菜单

## 五、验收标准汇总

### 登录模块
| 用户故事 | 验收要点 |
|----------|----------|
| US001/US101/US201 | 正确账号登录成功；错误账号提示错误；禁用账号提示禁用 |

### 商品模块
| 用户故事 | 验收要点 |
|----------|----------|
| US003 | 新增SPU成功；必填校验 |
| US004 | 编辑保存成功 |
| US005 | 新增SKU成功；规格联动 |
| US104 | 上架/下架生效 |

### SN码模块
| 用户故事 | 验收要点 |
|----------|----------|
| US006 | 手动录入成功；重复校验 |
| US007 | CSV导入成功/失败提示 |
| US008 | 查询显示状态 |

### 客户模块
| 用户故事 | 验收要点 |
|----------|----------|
| US108 | 列表分页；搜索筛选 |
| US109 | 余额/积分调整 |

### 订单模块
| 用户故事 | 验收要点 |
|----------|----------|
| US110 | 列表分页；状态筛选 |
| US112 | 退款审核通过/拒绝 |

### 系统模块
| 用户故事 | 验收要点 |
|----------|----------|
| US202 | 员工列表分页 |
| US203 | 新增员工；角色权限复制 |
| US205 | 权限添加/移除 |
