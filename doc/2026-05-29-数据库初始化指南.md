# 数据库初始化指南

## 概述

本地开发环境基于 Docker 容器化数据库（MySQL + MongoDB），通过 PowerShell 脚本进行初始化和清理，业务数据通过后端 API 接口写入。

---

## 环境要求

| 依赖 | 说明 |
|------|------|
| Docker Desktop | 运行 MySQL / MongoDB 容器 |
| PowerShell 5.1+ | 执行初始化脚本 |
| JDK 17 | 运行后端应用以调用初始化 API |

---

## 快速开始

### 第一步：初始化数据库结构

在项目根目录执行：

```powershell
.\init-database.ps1
```

脚本自动完成：
- 停止并删除旧的 MySQL 容器及数据卷
- 启动新的 MySQL 容器并执行 `sql/init.sql` 建表
- 停止并删除旧的 MongoDB 容器及数据卷
- 启动新的 MongoDB 容器

### 第二步：启动后端服务

在 IntelliJ IDEA 中直接运行 `BackendApplication`，或在命令行执行：

```bash
cd Backend
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

默认使用 `local` profile，连接 `localhost` 上的数据库。

### 第三步：通过 API 初始化业务数据

后端启动后，调用初始化接口写入业务数据：

```bash
# 一键初始化全部数据
curl http://localhost:8080/api/admin/system/data/init
```

或在浏览器中直接访问：
```
http://localhost:8080/api/admin/system/data/init
```

## 其他操作

### 清空数据（不清除表结构）

```powershell
.\clean-database.ps1
```

只 truncate 业务表 + 清空 MongoDB 翻译数据，容器继续运行。清空后重新调用 `/init` API 即可。

### 追加数据

```bash
# 按模块追加指定条数
curl -X POST http://localhost:8080/api/admin/system/data/append \
  -H "Content-Type: application/json" \
  -d '{"module": "customer", "count": 20}'

# 支持 GET 方式
curl "http://localhost:8080/api/admin/system/data/append?module=customer&count=20"
```

## 完整流程示例

```powershell
# 1. 重建数据库容器和表结构
.\init-database.ps1

# 2. 启动后端（IntelliJ 或命令行）

# 3. 初始化业务数据
curl http://localhost:8080/api/admin/system/data/init
```

## 常见问题

**Q: 初始化 API 返回 401？**
A: 需要先登录获取 Token。在开发阶段可临时禁用安全配置，或通过登录接口获取 Token 后携带访问。

**Q: 容器端口被占用？**
A: 检查 `docker-compose.yml` 中端口映射，可修改宿主机端口（如 `3307:3306`），同时修改 `application-local.yml` 中对应端口。

**Q: MySQL 连接失败？**
A: 确保容器已正常运行：`docker ps | findstr salemanager-mysql`
