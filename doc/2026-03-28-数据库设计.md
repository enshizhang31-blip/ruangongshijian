## 三、核心表结构

### 1. 商品模块（SPU + SKU + SN码）

#### 1.1 SPU商品表（标准产品单位）

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(128) | SPU名称 | NOT NULL |
| category_id | BIGINT | 分类ID | FOREIGN KEY |
| brand | VARCHAR(64) | 品牌 | |
| image_url | VARCHAR(512) | 主图片URL | |
| images | TEXT | 多图片JSON数组 | |
| description | TEXT | 商品描述 | |
| status | TINYINT | 状态：0下架 1上架 | DEFAULT 0 |
| created_at | DATETIME | 创建时间 | |
| updated_at | DATETIME | 更新时间 | |

**说明**：SPU是抽象的商品概念，如"iPhone 15"，不涉及具体规格和价格。

#### 1.2 SKU规格表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| spu_id | BIGINT | SPU ID | FOREIGN KEY |
| sku_code | VARCHAR(32) | SKU编码 | NOT NULL, UNIQUE |
| spec_json | JSON | 规格JSON，如：{"color": "黑色", "memory": "256G"} | |
| price | DECIMAL(10,2) | 销售价格 | NOT NULL, DEFAULT 0 |
| cost_price | DECIMAL(10,2) | 成本价 | |
| unit | VARCHAR(16) | 单位 | DEFAULT '件' |
| image_url | VARCHAR(512) | SKU图片（可覆盖SPU图片） | |
| status | TINYINT | 状态：0禁用 1启用 | DEFAULT 1 |
| created_at | DATETIME | 创建时间 | |
| updated_at | DATETIME | 更新时间 | |

**说明**：
- SKU = SPU + 规格组合，如"iPhone 15 黑色 256G"
- SKU编码在同一SPU下唯一，如 `IP15-BLK-256`

**索引**：
- `idx_spu_id` (spu_id)
- `idx_sku_code` (sku_code) - 唯一

#### 1.3 SN码表（商品实例）

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| sn_code | VARCHAR(64) | SN码（全球唯一） | NOT NULL, UNIQUE |
| sku_id | BIGINT | SKU ID | FOREIGN KEY |
| spu_id | BIGINT | SPU ID（冗余） | |
| spu_name | VARCHAR(128) | SPU名称 | |
| sku_code | VARCHAR(32) | SKU编码（冗余） | |
| spec_json | JSON | 规格JSON（冗余） | |
| price | DECIMAL(10,2) | 录入时的价格 | |
| status | TINYINT | 状态：0在库 1已售 2已作废 3退货中 4已退货 | DEFAULT 0 |
| source | TINYINT | 来源：1手动 2CSV 3自动生成 | DEFAULT 1 |
| created_at | DATETIME | 录入时间 | |
| sold_at | DATETIME | 销售时间 | |
| updated_at | DATETIME | 更新时间 | |

**说明**：
- SN码 = 具体的商品实例，每台实际的商品有唯一的SN码
- 1个SKU可以有多个SN码（如100台iPhone 15黑色256G）
- 库存通过统计SN码数量计算

**索引**：
- `idx_sn_code` (sn_code) - 唯一，查询效率最高
- `idx_sku_id` (sku_id)
- `idx_status` (status)
- `idx_created_at` (created_at)

**状态说明**：
| 值 | 说明 |
|----|------|
| 0 | 在库（可销售） |
| 1 | 已售（已卖出） |
| 2 | 已作废（无效码） |
| 3 | 退货中（申请退货） |
| 4 | 已退货（已退回库） |

#### 1.4 SN码操作日志表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| sn_code_id | BIGINT | SN码ID | FOREIGN KEY |
| sn_code | VARCHAR(64) | SN码（冗余） | |
| sku_id | BIGINT | SKU ID | |
| operation | VARCHAR(32) | 操作类型：录入/销售/作废/退货 | NOT NULL |
| from_status | TINYINT | 操作前状态 | |
| to_status | TINYINT | 操作后状态 | |
| operator_id | BIGINT | 操作人ID | |
| operator_name | VARCHAR(64) | 操作人姓名 | |
| remark | VARCHAR(256) | 备注 | |
| created_at | DATETIME | 操作时间 | |

#### 1.5 商品分类表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(64) | 分类名称 | NOT NULL |
| parent_id | BIGINT | 父级ID | DEFAULT 0 |
| icon | VARCHAR(255) | 图标URL | |
| sort | INT | 排序 | DEFAULT 0 |
| status | TINYINT | 状态 | DEFAULT 1 |

| updated_at | DATETIME | 更新时间 | |

#### 1.6 规格名称表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(32) | 规格名称，如颜色、尺寸、内存 | NOT NULL |
| sort | INT | 排序 | DEFAULT 0 |
| status | TINYINT | 状态 | DEFAULT 1 |

#### 1.7 规格值表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |

| sort | INT | 排序 | DEFAULT 0 |
| status | TINYINT | 状态 | DEFAULT 1 |

### 4. 权限模块（管理端）

> 关联文档：[api-admin-system.md - 权限模型说明](../doc/api/Web管理端/api-admin-system.md)

#### 4.1 员工表

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| username | VARCHAR(64) | 用户名 | NOT NULL, UNIQUE |
| password | VARCHAR(128) | 密码（BCrypt加密） | NOT NULL |
| real_name | VARCHAR(64) | 真实姓名 | |
| phone | VARCHAR(20) | 手机号 | |
| email | VARCHAR(128) | 邮箱 | |
| permissions | JSON | 权限数组 | 创建时从角色复制，之后独立 |
| routes | JSON | 路由数组 | 创建时从角色复制，之后独立 |
| department_id | BIGINT | 部门ID | |
| status | TINYINT | 状态 | DEFAULT 1 |
| last_login_at | DATETIME | 最后登录时间 | |
| created_at | DATETIME | 创建时间 | |
| updated_at | DATETIME | 更新时间 | |

**说明**：
- 员工表中不存储 role_id
- permissions: 权限数组（创建时从角色复制，之后独立）
- routes: 路由数组（创建时从角色复制，之后独立）
- 有效权限 = 员工的 permissions
- 有效路由 = 员工的 routes

#### 4.2 角色表（预设模板）

| 字段 | 类型 | 说明 | 约束 |
|------|------|------|------|
| id | BIGINT | 主键 | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(64) | 角色名称 | NOT NULL, UNIQUE |
| code | VARCHAR(32) | 角色编码 | NOT NULL, UNIQUE |
| description | VARCHAR(256) | 角色描述 | |
| permissions | JSON | 预设权限数组 | 如：`["spu:*", "order:*"]` |
| routes | JSON | 预设路由数组 | 如：`["/dashboard", "/product"]` |
| is_preset | TINYINT | 是否预设：1预设 | DEFAULT 1 |
| status | TINYINT | 状态 | DEFAULT 1 |
| created_at | DATETIME | 创建时间 | |
| updated_at | DATETIME | 更新时间 | |

**预设角色**：
| id | name | code | permissions | routes |
|----|------|------|-------------|--------|
| 1 | 超级管理员 | SUPER_ADMIN | `["*"]` | 所有路由 |
| 2 | 运营主管 | OPERATOR | `["spu:*", "sku:*", "category:*", "spec:*", "sn:*", "customer:*", "order:*", "statistics:*"]` | /dashboard, /product, /sn, /customer, /order, /statistics |
| 3 | 录入员 | INPUTTER | `["spu:add", "spu:edit", "spu:view", "sku:add", "sku:edit", "sku:view", "sn:add", "sn:import", "sn:view", "sn:query"]` | /dashboard, /product, /sn |

> **说明**：角色仅作为预设模板，不可新增、编辑、删除。员工创建时，Java从角色模板复制权限到员工表。

**权限标识说明**：
| 格式 | 说明 |
|------|------|
| `*` | 所有权限（超级管理员） |
| `spu:*` | SPU模块所有权限 |
| `spu:view` | 查看SPU |
| `spu:add` | 新增SPU |
| `spu:edit` | 编辑SPU |
| `spu:delete` | 删除SPU |
| `sku:*` | SKU模块所有权限 |
| `sn:*` | SN码模块所有权限 |
| `customer:*` | 客户模块所有权限 |
| `order:*` | 订单模块所有权限 |

## 六、SPU/SKU/SN码层级关系

```
SPU（标准产品单位）
├── 抽象的 商品概念
├── 如：iPhone 15
└── 不涉及具体规格和价格

SKU（规格组合）
├── SPU + 规格组合
├── 如：iPhone 15 黑色 256G
├── 有独立的 price、image_url
└── 库存通过 SN码 数量计算

SN码（商品实例）
├── SKU 的具体实例
├── 如：序列号 SN202403010001
├── 1个SKU可以有多个SN码
└── 库存 = 在库状态(0)的SN码数量
```

## 七、权限设计说明

> 详细说明见 [api-admin-system.md - 权限模型说明](../doc/api/Web管理端/api-admin-system.md)

### 权限模型（角色是预设模板，权限在员工级别管理）

```
角色（预设模板）
├── 预设权限数组 permissions
├── 预设路由数组 routes
└── 不可修改：SUPER_ADMIN, OPERATOR, INPUTTER

员工
├── role_id: 记录所属角色（仅用于显示）
├── permissions: 权限数组（创建时从角色复制，之后独立）
├── routes: 路由数组（创建时从角色复制，之后独立）

有效权限 = 员工的 permissions
有效路由 = 员工的 routes

⚠️ 创建后与角色无关，修改角色不影响现有员工
```

### 权限计算

| 员工 | permissions |
|------|-------------|
| 张三（运营主管） | 创建时复制角色的权限，之后独立 |
| 李四（录入员） | 创建时复制角色的权限，之后独立 |

### 权限检查流程

```
1. 员工登录，获取自身的 permissions 和 routes
2. 前端：
   - 路由守卫：检查路由是否在 routes 中
   - 按钮控制：v-permission 指令检查权限
3. 后端：
   - 接口注解：@PreAuthorize("hasPermission('spu:delete')")
```

### 设计说明

| 设计 | 说明 |
|------|------|
| 角色是预设模板 | 预设角色不可修改，作为新员工初始权限的来源 |
| 员工独立权限 | 创建时从角色复制，之后与角色无关 |
| 修改角色 | 仅影响新员工，不影响现有员工 |

### 9.3 商品价格数据流

```
┌─────────────────────────────────────────────────────────────┐
│  1. 用户请求商品：Header: X-Locale: en-US                  │
├─────────────────────────────────────────────────────────────┤
│  2. 查询 MySQL                                              │
│     - SPU表：id, name, category_id                         │
│     - SKU表：id, spu_id, price(CNY), spec_json            │
├─────────────────────────────────────────────────────────────┤
│  3. 查询 MongoDB                                            │
│     - goods_i18n.locales["en-US"].name                    │
│     - goods_i18n.locales["en-US"].currency = "USD"        │
├─────────────────────────────────────────────────────────────┤
│  4. 获取汇率（Redis缓存）                                    │
│     - exchange_rate:CNY:USD = 0.138                        │
├─────────────────────────────────────────────────────────────┤
│  5. 计算价格                                                │
│     - price = 6999 × 0.138 = 965.86 USD                    │
├─────────────────────────────────────────────────────────────┤
│  6. 返回响应                                                │
│     { id: 1, name: "iPhone 15 Pro", price: 965.86,         │
│       currency: "USD", custom_attrs: [...] }               │
└─────────────────────────────────────────────────────────────┘
```

|--------|------|-------------|
| `goods_i18n` | 商品多语言翻译 | goods (SPU) |
