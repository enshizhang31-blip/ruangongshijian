### 组件模块

#### 通用组件 (common/)

| 组件 | 说明 | 依赖 |
|------|------|------|
| `StatCard` | 统计卡片，支持趋势显示 | Heroicons |
| `EmptyState` | 空状态占位 | Heroicons |
| `LoadingSpinner` | 加载中指示器 | Heroicons |
| `ConfirmDialog` | 确认对话框 | Modal, Heroicons |
| `ImageUploader` | 图片上传 | - |
| `StatusBadge` | 状态标签 | - |
| `TagInput` | 标签输入 | Heroicons |

#### 业务组件

| 组件 | 说明 | 所属模块 |
|------|------|----------|
| `ProductTable` | 商品列表表格 | product |
| `ProductSelect` | 商品下拉选择 | product |
| `CustomerTable` | 客户列表表格 | customer |
| `CustomerSelect` | 客户下拉选择 | customer |
| `SaleOrderTable` | 销售订单表格 | sale |
| `QuickStats` | 仪表盘统计卡片 | dashboard |

### UI 设计

#### 色彩系统

| 用途 | 颜色 | 编码 |
|------|------|------|
| 主色 | Blue | `#0f62fe` (Arco Blue) |
| 成功 | Green | `#00b42a` |
| 警告 | Orange | `#ff7d00` |
| 危险 | Red | `#f53f2c` |
| 信息 | Purple | `#722ed1` |

#### 响应式断点

| 断点 | 宽度 | 用途 |
|------|------|------|
| xs | < 576px | 超小屏手机 |
| sm | ≥ 576px | 小屏平板 |
| md | ≥ 768px | 中屏平板 |
| lg | ≥ 992px | 小屏桌面 |
| xl | ≥ 1200px | 大屏桌面 |

#### 布局结构

- **Desktop (≥md)**: 左侧固定 Sidebar + 顶部 Header + 内容区
- **Mobile (<md)**: 底部固定 BottomNav + 全屏内容区

### Arco Design 组件使用

| 组件 | 用途 | 使用位置 |
|------|------|----------|
| `Menu/MenuItem` | 侧边栏导航 | Sidebar |
| `Card` | 页面卡片容器 | 所有列表页 |
| `Table` | 数据表格 | Product/Customer/Sale |
| `Button` | 按钮 | 全局 |
| `Input` | 输入框 | SearchBar, Forms |
| `Form/FormItem` | 表单 | Login |
| `Tag` | 状态标签 | Table rows |
| `Avatar` | 用户头像 | Header |
| `Dropdown` | 下拉菜单 | Header |
| `Statistic` | 统计数字 | Dashboard |
| `Row/Col` | 栅格布局 | Dashboard |
| `Space` | 间距 | 全局 |
| `Popconfirm` | 删除确认 | Table |
