# 🎬 SaleManager 演示版（小程序）启动指南

> 用最小可演示版本覆盖登录注册、商品浏览/购买、购物车、多语言切换、订单状态与运输中、退款申请。

---

## 1. 一句话讲明白演示场景

> 这是一套支持 **后端可控多语言** 的零售小程序演示版。后台可以在 yaml 里决定哪个语言上线/下线；用户在「我的」页面里就能看见当前可选语言并即时切换。

## 3. 启动步骤

### 3.1 数据库（必须，只跑一次）

```bash
# 全新建库
mysql -uroot -p < sql/schema.sql

# 旧库（已建过 customer 表但缺 password 列），跑这个就够了
mysql -uroot -p your_db < sql/demo_init_all.sql
```

`demo_init_all.sql` 做了两件事：
1. 给 `customer` 表加上演示版新增的 `password` 列（幂等 ALTER）
2. 备注一段手工插入演示账号的 SQL（**正常不需要执行**，后端启动会自动 seed）

### 3.2 后端（必须）

```bash
cd Backend && .\mvnw.cmd spring-boot:run
# 默认端口 8080
```

启动后会自动 seed 一个演示账号：
- 手机号（用户名）：`demo`
- 密码：`123456`
- 等级：钻石会员（4），余额 ¥9999，积分 9999

### 3.3 小程序（uni-app）

```bash
cd Uniapp
npm install
npm run dev:mp-weixin   # 微信小程序
# 或
npm run dev:h5          # H5 浏览器演示
```

编译成功后用 **微信开发者工具**导入 `Uniapp/dist/dev/mp-weixin` 即可预览。
默认 baseURL 在 `src/utils/request.js` 指 `http://localhost:8080`，
小程序端请打开"不校验合法域名"或自行修改。

### 3.4 Web 管理端（可选）

```bash
cd Fronted && npm install && npm run dev
```

## 4. 后端可控多语言

**只改 application.yml，无需重新部署前端。**

```yaml
i18n:
  default-locale: zh-CN
  supported-locales:
    - zh-CN
    - en-US
    - ja-JP
    # - ko-KR   # 注释即下线，前端不会再展示
```

重启后端，前端下次进入「我的」页面会自动重新拉取 `GET /api/i18n/locales`。

## 7. 演示流程（5 分钟版）

1. **多语言**（无需登录）→「我的」→「语言」→ English / 日本語 切换
2. **登录** → 「我的」头像 → 演示按钮一键登录（demo / 123456）
3. **购买** → 首页/商品 → 详情 → 立即购买
4. **订单演示** → 「我的」→ 我的订单 → 「运输中」tab → 看到 2 个运输中订单
5. **物流详情** → 进入任一运输中订单 → 看 4 节点物流轨迹 + 申请退款
6. **后端可控**（可选）→ 后端 yaml 注释 `en-US` 重启 → 进入小程序 → 列表里 English 消失

## 8. FAQ

**Q1: 后端没启动时登录会怎样？**
A: 显示网络错误。购物车/订单列表/详情都已做本地兜底（demo 订单一键造），即使接口失败仍能演示。

**Q2: 「运输中」订单在什么状态？**
A: 状态码 2（已发货）。订单详情页根据状态动态生成 4 个物流时间点（mock）。

**Q3: 语言切换后 TabBar 的中文不会变？**
A: App.vue 的 `refreshTabBar()` 会在 onLaunch 后 500ms / 切换语言时调用 `uni.setTabBarItem` 自动更新。

**Q4: 后端控制语言上线/下线的最快验证方法？**
A: 修改 application.yml 的 `i18n.supported-locales`，去掉 `en-US`，重启后端。前端再次进入小程序时，「我的」页语言切换列表里 English 就消失了。

**Q5: 我能不能自定义演示数据？**
A: 可以。订单列表里点「Demo」按钮会写 6 条到 `uni.storage('demo-orders')`，可以打开调试器清除。

**Q6: 编译报 "Could not find files" 怎么解决？**
A: 用项目自带的 mvnw：`cd Backend && .\mvnw.cmd spring-boot:run`。
