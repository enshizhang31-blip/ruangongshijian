# 销售管理系统 (SaleManager)

企业级销售管理平台，支持小程序 + Web 端管理。

## 项目结构

```
SaleManagerSys
├── Backend/                 # 后端服务 (Java SpringBoot)
├── Fronted/                 # Web 管理端 (Vue3 + Arco Design)
│                          # 包含：商品管理、SN码录入、订单管理、客户管理等
├── Uniapp/                  # 用户端小程序 (uni-app)
├── doc/                    # 项目文档
├── sql/                     # 数据库脚本
└── .claude/                 # Claude Code 配置
    └── rules/               # 编码规范
```

## 系统架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              后端 API (SpringBoot)                          │
│                    统一认证 · 动态路由 · 权限控制 · 数据服务                  │
└─────────────────────────────────────────────────────────────────────────────┘
              ↑                       ↑                       ↑
              │                       │                       │
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│     Fronted     │       │     Uniapp      │       │    Backend      │
│   (Web管理端)   │       │  (用户端小程序)   │       │   (后端API)     │
├─────────────────┤       ├─────────────────┤       ├─────────────────┤
│• 商品批量管理    │       │• 商品浏览        │       │• 业务逻辑       │
│• CSV导入导出     │       │• 购物车          │       │• 数据持久化     │
│• SN码录入/查询  │       │• 下单支付        │       │• 认证授权       │
│• 订单管理       │       │• 会员中心        │       │• 权限控制       │
│• 客户管理       │       │• 积分兑换        │       │• 统计报表       │
│• 数据统计       │       │• 订单查询        │       │• 多语言支持     │
│• 动态路由       │       │                 │       │  (MySQL+MongoDB)│
│• 权限控制       │       │                 │       │                 │
└─────────────────┘       └─────────────────┘       └─────────────────┘
```

## 技术栈

### 后端 (Backend)
- SpringBoot 2.7.x
- MyBatis-Plus
- MySQL 8.0 + MongoDB（多语言）
- SpringSecurity + JWT
- Redis（汇率缓存）

### Web管理端 (Fronted)
| 类别 | 技术 | 版本 |
|------|------|------|
| 框架 | Vue | 3.5.30 |
| 构建 | Vite | 7.3.1 |
| 状态管理 | Pinia | 3.0.4 |
| 路由 | Vue Router | 5.0.3 |
| UI框架 | Arco Design Web Vue | 2.57.0 |
| CSS | Tailwind CSS | 4.2.2 |
| HTTP | Axios | 1.13.6 |
| 图标 | Heroicons | 2.2.0 |
| 图表 | ECharts | 6.0.0 |

### 小程序端 (Uniapp)
- uni-app
- uView 2.0

## 模块功能

| 模块 | 说明 | 端 |
|------|------|-----|
| 动态路由权限 | 路由存储数据库，动态注册，权限控制 | Web |
| 商品管理 | SPU/SPU管理、商品分类、规格属性 | Web |
| SN码管理 | SN码录入/查询/操作记录、批量导入导出(CSV) | Web |
| 订单管理 | 订单列表、状态管理、退款审核 | Web |
| 客户管理 | 客户资料、会员等级、积分余额 | Web |
| 数据统计 | 销售统计、报表导出 | Web |
| 多语言支持 | 商品/分类翻译、汇率计算（MySQL+MongoDB） | 通用 |
| 用户端商城 | 商品浏览、购物车、下单支付、会员中心 | Uniapp |
