# 销售管理系统 (SaleManager)

企业级销售管理平台，支持小程序 + Web 端管理。

## 项目结构

```
SaleManagerSys
├── Backend/                 # 后端服务 (Java SpringBoot)
├── Fronted/                 # Web 管理端 (Vue3 + Arco Design)
├── Uniapp-User/            # 用户端小程序 (uni-app)
├── Uniapp-Admin/           # 管理端小程序 (uni-app)
├── docs/                    # 项目文档
└── sql/                     # 数据库脚本
```

## 技术栈

### 后端 (Backed)
- SpringBoot 2.7.x
- MyBatis-Plus
- MySQL 8.0
- SpringSecurity + JWT
- Redis

### Web管理端 (Fronted)
- Vue 3.5.x + TypeScript
- Vue Router 5 (动态路由)
- Pinia 3 (状态管理)
- Vite 7 (构建工具)
- Arco Design Web Vue
- Tailwind CSS
- ESLint + Prettier (代码规范)

### 小程序端 (Uniapp)
- uni-app
- uView 2.0

## 模块功能

| 模块 | 说明 | 端 |
|------|------|-----|
| 动态路由权限 | 路由存储数据库，动态注册，权限控制 | Web |
| 商品管理 | 商品CRUD、分类管理、SN码管理 | Web |
| SN码管理 | 手动录入、批量导入导出(CSV) | Web |
| 订单管理 | 订单列表、状态管理 | Web |
| 客户管理 | 客户资料、会员管理 | Web |
| 数据统计 | 销售统计、报表导出 | Web |
| 用户端商城 | 商品浏览、购物车、下单支付、会员中心 | 用户小程序 |
| 管理端录入 | SN扫码录入/编辑/查询 | 管理小程序 |
